# blogApp

A responsive news web application built with React and Tailwind CSS that fetches and displays news articles using an external API.

## Features

- Fetch news from external API
- Browse latest headlines
- Responsive design
- Pagination
- Clean UI

## Tech Stack

- React
- Tailwind CSS
- JavaScript
- Axios / Fetch API
